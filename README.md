# Kaze — Weather Visualization App

Kaze is a **personal React weather visualization project** that provides a clean and simple way to check live weather conditions and forecasts.

## Features

- View weather based on your current location
- Select cities and municipalities in NCR and Region III
- View current weather conditions
- Check hourly and 7-day forecasts
- View temperature, humidity, wind, rainfall, sunrise, and sunset
- Automatic weather refresh every 15 minutes
- Responsive and mobile-friendly design

## Development

Kaze was created as an **AI-assisted personal project**. AI tools were used to assist with coding, debugging, API integration, UI design, animations, and development improvements.

The final website was manually refined to achieve the desired functionality and design.

## Design

Kaze uses a **clean white and blue glassmorphism design** with smooth animations, gradients, and modern responsive layouts.
